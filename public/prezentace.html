Stanov si cíl

Uživatel vytvoří cíl výletu (název, zaměření, obtížnost) a k němu plánuje jednotlivé destinace.

Sleduj rozpočet

Aplikace agreguje metriky — počet destinací, celkové dny pobytu a odhadovaný rozpočet cesty.

Měj přehled

Filtrování a detail cíle ukazují kompletní plán — bez tabulek a rozptýlených poznámek.

Cílem je jednoduchý, ale úplný nástroj: od definice cíle výletu přes evidenci destinací až po vyhodnocení času a nákladů — vše přes REST API a webové UI.

1 nejdůležitější BUC

BUC: Přidat destinaci

Aktér & cíl

  • Plánovač výletů
    chce ke svému cíli přidat novou destinaci
  • Vstup
    name, estimatedDurationDays, dailyBudget + tripGoalId z URL
  • Výstup
    vytvořená destinace s vygenerovaným id a aktualizované metriky v UI

Hlavní scénář

  • Uživatel otevře detail cíle a klikne „Nová destinace"
  • Vyplní název, délku pobytu a denní rozpočet
  • Validace vstupu (kladná délka, kladný rozpočet)
  • Ověření, že cíl tripGoalId existuje
  • INSERT do SQLite + refresh detailu v UI

Alternativy: neplatný vstup → 400, neexistující cíl → 404.

Přístup přes db.prepare() v route handleru — validace probíhá před SQL operací. API vrací camelCase (tripGoalId, estimatedDurationDays).

Nejdůležitější BE endpoint

POST  /v1/trip-goals/:tripGoalId/destinations

Request body

{ "name": "Praha", "estimatedDurationDays": 3, "dailyBudget": 2500 }

Response 201

{ "id": 5, "tripGoalId": 2, "name": "Praha", "estimatedDurationDays": 3, "dailyBudget": 2500 }

Tento endpoint realizuje BUC Přidat destinaci — validace → kontrola cíle → INSERT → JSON response.
